This directory will contain our runtime algorithms. The runtime work should converge around the same
thesis: maximize large batched matrix multiplications, minimize memory movement, minimize data
movement, make reads large, and use tiling when it improves locality or throughput.

The priority is maximal compute utilization through compute-bound fused operations. This includes
techniques such as continuous batching, fused-kernel attention, FlashAttention, speculative
decoding, and Eagle 3 speculative decoding.

Scheduling should treat GPU, CPU, and NVMe as one constrained placement problem. FlexGen is the
baseline reference for using linear programming to choose tensor placement and movement under
limited GPU memory. Apple's LLM in a flash paper is the baseline reference for flash-aware loading:
reuse active data, avoid unnecessary transfers, and prefer larger contiguous reads.
